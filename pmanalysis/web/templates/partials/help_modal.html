About PolyScripts Analysis

What this is

PolyScripts Polymarket Analysis is a live research terminal for Polymarket BTC, ETH, and SOL Up or Down markets on 5-minute and 15-minute clock windows. It streams Chainlink oracle and TWAP, Binance spot, and Polymarket CLOB quotes, records every window, and lets you replay history.

This tool does not place trades or connect to your wallet. It is for monitoring, timing, and offline research only.

Built by PolyScripts.

How traders use it

  • Pick an asset and interval in the left Markets panel and watch the live HUD (initial TWAP, Chainlink, 60s TWAP, difference, countdown).
  • Use the price and probability charts for the current window; the target line is the window-open TWAP (price to beat).
  • At each 5m/15m boundary the terminal rolls to the new slug automatically — no manual refresh.
  • Open History to browse resolved windows, UP/DOWN win rates, and replay ticks.
  • Use Status to check Binance, Chainlink, and CLOB feed health on your collector.
  • Load a past slug from the window dropdown or sidebar previews to study a single window in detail.

API for your backtest app

Point your backtest machine at this collector’s base URL (same host as this dashboard, e.g. http://127.0.0.1:8000). The /v1 dataset API is public JSON — no API key required.

  1. GET /v1/coverage — see which date range is archived per market.
  2. POST /v1/datasets — request a zip for a start/end time and markets (e.g. BTC 5m).
  3. GET /v1/datasets/{id} — poll until status is ready.
  4. GET /v1/datasets/{id}/download — save the zip and run locally (no live API during the backtest).

Example (from a machine that can reach this collector):

python scripts/fetch_dataset.py --url YOUR_COLLECTOR_URL --start 2026-10-01T00:00:00Z --end 2026-10-27T00:00:00Z --asset BTC --interval 5m

Full API contract: docs/history-dataset.md in the project repository (coverage, dataset schema, parquet layout, and cache rules).
